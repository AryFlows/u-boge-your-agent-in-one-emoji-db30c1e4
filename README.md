One emoji that stands for my AI agent: **🦾** — the mechanical arm.

An agent is not a face and not a whole robot. It is the arm that does the
work for you: it reaches, grabs, builds, and hands things back while you
watch. One glyph, instantly readable, specific about how the agent works.

`main.ts` (Node stdlib only) writes the emoji to `/output/entry.txt`.
